# fancy-marks.nvim

## Overview

This plugin is designed to provide a way to view and jump to marks in Neovim, as well as highlight them when an overlay is enabled.

## Installation

Assuming the plugin is in the _runtimepath_, the setup function can be called with `require("fancy-marks").setup({})` (or with your preferred plugin manager).
